IMPORT CALENDAR EVENTS

Import events from Google Calendar

In Google Calendar, open Settings → Integrate calendar and copy the Secret address in iCal format. Treat this link like a password: anyone with it can read your events.

This imports event titles and times once. Ollama assigns a category and importance. Rebuild stores the private link, but does not sync automatically. To update events, submit the link again.
